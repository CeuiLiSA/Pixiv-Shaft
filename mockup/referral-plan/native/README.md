# Android 原生预览

入口：侧边栏「App 推荐计划 · 预览」，或新版「我的」→「其他」→同名入口。

实现位于 `app/src/main/java/ceui/pixiv/ui/referral/`，通过 `TemplateRoute.REFERRAL_PLAN` 打开。页面使用原生 View；票卡、轨道与装饰使用 Canvas；字体复用 App 内 Montserrat 400–800 字重。默认配色跟随 `V3Palette`，演示控制台可选择原型紫、玫瑰与青绿，页头可切换日夜。

已实现任务筛选、任务详情、邀请文案与系统分享、提交与补充表单、模拟审核、领取、卡包和激活。示例状态由独立 ViewModel / SavedStateHandle 管理，可随页面重建恢复；重新进入一条全新页面实例时恢复初始示例。没有调用奖励接口，也没有修改账号会员权益。

后续接入接口时，由服务端提供活动规则、邀请归因链接、任务进度、审核结果、奖励领取与激活结果。当前演示控制台与本地状态转换不能作为线上奖励判据。

## 本轮验证

- `:app:assembleGithubDebug` 通过。
- `ReferralDemoRepositoryTest` 6 项通过：审核与领取前置条件、重复领取保护、补充重提、输入校验、激活顺延与重复保护、到期边界、邀请进度约束。

- 已安装并运行于 Pixel 8 真机（1080 × 2400，420 dpi）。
- [真机页面截图](pixel8-preview.png) 与 [演示控制台截图](pixel8-demo.png)。截图配色为设备当前 App 主题，页面为用户当时正在体验的卡包空态。

原型对照以相同逻辑宽度、相同主题和字体缩放为准；Android 状态栏、手势区域、系统中文字体与至少 48dp 的主要操作热区会产生平台差异。本轮截图确认了真机显示；尚未做全部深浅主题、放大字体和横屏状态的真机截图验收。
