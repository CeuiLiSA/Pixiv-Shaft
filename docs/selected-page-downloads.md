# 选页下载与单张保存管理

多 P 作品可选择其中几页交给现有下载管理器执行；大图页发起的保存任务可在独立子页集中查看。相关讨论：#1316、#1312。

## 入口与行为

- 图片详情的翻译菜单中，在「圈选翻译」下方点击「选择多页下载」；作品详情（经典 / V3）的「更多」菜单中，入口紧接「智能抠图」。
- 快捷方式：详情页长按下载按钮，在分辨率菜单末尾选择选页下载；大图页长按保存按钮直接打开网格。单击仍保存当前显示图片。
- 默认选择当前页，支持多选、全选/取消全选、仅当前页及选择未下载页。
- 缩略图复用页面预览模型；既有页面预览仍保持点击跳页的行为。
- 所选页使用设置中的默认下载分辨率，通过 `Manager.addTasks` 提交页级任务，由既有逻辑去重和调度；此操作不新增未选页任务，也不创建整作品批量队列记录。
- 分页信息不完整时先尝试补全；仍不可用的页跳过并提示，避免把所选页替换成封面。

## 下载管理

外层保留「批量队列 / 正在下载 / 已完成」。「正在下载」内增加横向「下载任务 / 单张保存」子 tab，点击切换；左右滑动仍交给外层页面。

- 「下载任务」继续显示原有任务，包括选页下载，使用原有批量操作。
- 「单张保存」观察进程级 `ImagePageSaver` 的原图保存状态，显示等待图片、等待写入、正在写入及失败原因。
- 等待阶段可取消；写盘开始后取消按钮禁用；失败可重试或移除记录。
- 单张保存使用独立操作，不受下载任务的批量暂停、继续、重试和清空控制。
- 译图沿用原有保存入口和记录规则，不进入原图保存列表。
- 成功后的文件和按页下载记录沿用现有实现；已完成页及 P 数显示不改。
- 原图保存意图与失败原因在开始执行前落入应用私有持久目录；应用启动时恢复被回收进程中断的任务，无需先打开下载页。失败项保留等待重试，进度按实际来源重算。
- 取消、完成和移除失败项在记录提交后更新列表；恢复时核对入队后写下且文件仍可读的完成记录，避免重复保存。本次不保证关闭应用期间持续下载，也不新增字节级续传或共享传输暂停；译图仍沿用原有进程级行为。

## 验收

自动测试 `PageDownloadSelectionTest` 覆盖合法页过滤、去重排序、全选切换、排除本地与既有任务、空选择恢复及快照隔离。新增 `ImagePageSaveJournalTest` 覆盖任务落盘、失败保留、清理、原子回滚与格式保护，`ImagePageSaverRecoveryTest` 覆盖启动恢复、恢复期间取消、移除失败项的提交时序及已完成页核对。

交互验收需覆盖：

1. 20P 作品只选择第 3、7、12 页，确认新增任务仅对应这三页，已有任务不会重复添加。
2. 旋屏保留页选择，包括手动取消全部后的空选择。
3. 慢网保存后退出大图，在「单张保存」查看进度、取消、失败重试和写盘阶段不可取消。
4. 同页保存与普通下载并发时沿用原有 URL 写锁；批量操作不取消保存任务。
5. 深浅主题、窄屏、平板、长标题、错误消息及字体放大。
6. 多张原图保存期间退到后台并用 `adb shell am kill <applicationId>` 回收进程，重新打开后自动恢复；失败项保留，已取消或移除的项不复活。文件和完成记录已写好但队列尚未清理时中断，恢复后不应重复写同页。

本改动只使用现有图源解析和保存后端。#1317 的原图续传与独立缓存可另行合入，之后需复核共享加载与缓存复用的集成行为。
